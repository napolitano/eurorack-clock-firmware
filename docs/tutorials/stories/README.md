# CLOCK Storybook Stories

Versioned tutorial source stories live here under `docs/tutorials/stories/`. They are documentation source, not simulator implementation.

- `examples/` contains parser/validator contract fixtures and deliberately invalid examples.
- [`external-sync.yaml`](external-sync.yaml) is already executable as the SB-3 semantic reference story. It is intentionally promoted before the broader SB-8 catalog because it locks down the hardest cable/generator/SOURCE/manual-STOP boundary.
- Additional production/reference stories are added alongside this README as SB-8 progresses.
- Generated frames, subtitles, videos, media probes and manifests belong under ignored generated output and never in source bundles.

A story controls CLOCK only through the Storybook action model. Product behaviour remains owned by production firmware and the existing simulator boundary.
