SYNC provides timing. In the factory AUTO source mode, connect an external clock and CLOCK waits for valid incoming edges before establishing lock. Once locked, external timing becomes the reference while SOURCE itself remains AUTO.

RST is different. It controls phase; it is not a second transport or clock-source input. Here we inject one reset pulse and the transport remains playing while the phase restarts.

[slower] Now press STOP manually. Even with external SYNC still present, CLOCK stays stopped. External timing must not silently override an explicit manual STOP.
