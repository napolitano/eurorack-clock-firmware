SYNC provides timing. In the factory AUTO source mode, connect an external clock to the SYNC input. CLOCK does not treat the physical cable alone as proof of a valid clock: it waits for accepted edges before establishing lock. Let the simulation run until the lock indication appears. Once locked, external timing becomes the reference while the SOURCE setting itself remains AUTO. You can watch the selected output in the scope.

RST is different. Patch it separately and hold its generator before sending one deliberate reset pulse. RST controls phase; it is not a second transport or clock-source input. Observe that the output’s phase restarts while the transport remains playing. SYNC continues providing the timing reference during this action.

[slower] Now press STOP slash BACK manually. Even with external SYNC still present and valid incoming pulses, CLOCK stays stopped. Watch the transport indication for a moment; there is no automatic restart from the clock edges. External timing must not silently override an explicit manual STOP.
